# FlowState — Modern SaaS Landing Page

> Where teams do their best work. Less noise. More flow.

A full multi-page SaaS website built in **ONE HTML file**. 

---

## ✨ Features

- 🏠 8 pages: Home, Product, Solutions, Pricing, Docs, About, Sign In, Sign Up
- 🛣️ Custom hash-based router (no React Router needed)
- 🎨 Tailwind CSS with custom brand tokens
- 🎬 Scroll reveal animations (IntersectionObserver)
- 💰 Interactive pricing toggle (Monthly / Annual)
- ❓ FAQ accordion
- 📱 Fully responsive, mobile-first
- 🌈 Animated gradient mesh + floating blobs
- ⚡ Zero build step — React + Babel via CDN

---

## 🛠️ Tech Stack

| Tech | Use |
|---|---|
| React 18 (CDN) | UI framework |
| Tailwind CSS (CDN) | Styling |
| Babel Standalone | In-browser JSX |
| Font Awesome 6.4 | Icons |
| Plus Jakarta Sans | Font |
